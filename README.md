# FiveM Zombie Survival Resource

LivingDead: A FEVZ is a configurable FiveM zombie resource that spawns hostile zombies near players, directs them to attack, and applies damage when they get close. Adjust zombie models, spawn limits, distances, health, and combat settings in the configuration file.

## Install

1. Place the resource folder in your FiveM server’s resources directory.
2. Add `ensure ender_zombies` to your `server.cfg` (use the actual folder name if it differs).
3. Start or restart the server.

## Use

1. Open `config.lua` to change the zombie models, spawn interval, distance limits, maximum number of zombies, and combat settings.
2. Set `Config.Enabled` to `true` to enable the resource or `false` to disable zombie spawning.
3. Restart the resource or server to apply configuration changes.
